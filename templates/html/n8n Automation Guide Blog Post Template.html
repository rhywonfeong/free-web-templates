# What Is n8n?

Think of n8n (pronounced “n-eight-n”) as a visual backend for your life. Instead of writing complex Python scripts, you drag and drop “nodes” onto a dark canvas, connect them with wires, and creating logic flows.

# Understanding Nodes

Trigger Nodes

Initiates the workflow (e.g., On Webhook, On Schedule, On Email Received).

Action Nodes

Performs a task (e.g., Create Record in Airtable, Send Slack Message).

AI Nodes

Integrates LLMs directly into the chain (e.g., OpenAI, LangChain Agents).
