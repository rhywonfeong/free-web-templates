Cara Pakai PDF Generator

Dokumentasi lengkap untuk mengotomatisasi pembuatan dokumen PDF massal menggunakan Google Spreadsheet dan Docs.

Persiapan Awal

1

Konfigurasi Spreadsheet

Duplikasi Template Master

Buka Spreadsheet "✅ Template - PDF Generator" melalui tautan di bawah ini, lalu buat salinan (Make a Copy) ke drive Anda.

Buka Template Master
File > Buat Salinan > Ubah nama file > Klik 'Buat Salinan'

Setup Sheet & Data

Duplicate sheet yang ada, rename sesuai kebutuhan. Buat header data dimulai dari Kolom D Baris ke-2. Isi data lengkap di bawah header tersebut.

Input Link Template

Masukkan link Google Docs (template) yang sudah Anda siapkan ke dalam kolom "TEMPALTE DOCS" di Spreadsheet. Pastikan akses link template adalah Editor.

Penting: Set permission ke "Anyone with the link" sebagai "Editor".

Registrasi Index

Tambahkan link spreadsheet Anda ke file Index Pusat agar tercatat sistem.

Buka File Index

Buka sheet INDEX > pilih kolom "edit rapor" > Cari list atau buat baru lalu paste link spreadsheet tersebut > Centang jika selesai generate.

Eksekusi

Kembali ke spreadsheet Anda. Klik menu custom Action > START.

START STOP REMOVE ERROR
2

Penyimpanan Data

Folder Otomatis

Semua data hasil generate akan disimpan otomatis di Google Drive Anda dalam folder bernama "DATA PDF GENERATOR".

  • File bersifat Public (dapat diakses via link).
  • Hati-hati saat menghapus file jika masih diperlukan.
3

Membuat Template

Gunakan variabel dinamis untuk menghubungkan data spreadsheet ke dokumen.

1. Salin Master Template

Pilih sheet "TEMPLATE 1", copy link kolom B baris 3.

File > Buat Salinan > Rename

2. Format Variabel

Gunakan kurung kurawal ganda untuk data dinamis.

{{kolom1}}
{{kolom2}}
Penting: ubah data dinamis dengan {{kolom + nomor kolom}} sesuai data.
4

Persiapan Data

Olah terlebih dahulu data yang ingin digenerate. Pastikan data bersih dan terformat dengan benar sebelum dipaste ke sheet input.

5

Otorisasi (Authorization)

Diperlukan hanya saat pertama kali menjalankan Action > Start pada spreadsheet baru.

1 Klik OK pada popup authorization required.
2 Pilih Akun Email Google Anda.
3 Klik Advanced (Lanjutan) di pojok kiri bawah.
4 Klik Go to Project (Unsafe).
5 Centang "Select All" lalu klik Continue.

Catatan Penting (Troubleshooting)

  • Limit Harian: Jika terjadi error, biasanya karena mencapai batas limit harian Google (sekitar 1000 generate/hari untuk akun Gmail biasa).
  • Revisi Data: Jika ada kesalahan data setelah generate, update data di spreadsheet terlebih dahulu, hapus link PDF di kolom hasil, lalu klik Action > START kembali.
