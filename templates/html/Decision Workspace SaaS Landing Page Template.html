Decided October 12, 2023

Migrate primary database to Postgres

Written by Sarah Jenkins

The Context

Our current NoSQL implementation is causing data consistency issues for the billing service. We need ACID compliance to ensure financial accuracy as we scale to the enterprise tier.

#eng-architecture discussion
Slack • 42 replies

The Decision

We will migrate the billing-service to PostgreSQL 15 managed on RDS. The migration will happen in Q4 using dual-write strategies to minimize downtime.
