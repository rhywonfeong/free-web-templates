The Problem

Microservices often suffer from "observability black holes." When a request fails, tracing the root cause across 50+ services takes hours of log parsing. Existing tools were either too expensive or lacked granular control over data retention.

The Solution

Synthetix introduces a lightweight sidecar architecture that aggregates traces with minimal overhead. It uses a custom compression algorithm (Z-Standard based) to reduce storage costs by 40% while maintaining millisecond-level query speeds.

Core Features

Real-time Visualization

WebSockets push metrics instantly to the dashboard with zero polling lag.

Role-Based Access

Granular permissions handled via JWT and Redis session management.

Distributed Tracing

OpenTelemetry compatible collectors that integrate with existing stacks.

Smart Alerting

Anomaly detection algorithms trigger alerts only on statistically significant deviations.

System Architecture

Client App

ClickHouse

Data is ingested via a high-throughput Golang collector, buffered through Kafka to handle backpressure, and finally stored in ClickHouse for OLAP aggregation.

Challenge: Write Throughput

Handling 50k+ events/second caused PostgreSQL to lock up during peak loads. Standard indexing strategies were insufficient for the volume of time-series data being generated.

> Migrated to TimescaleDB hyper-tables
> Implemented batch insertion (500ms windows)
> Reduced IOPS by 65%
