How to connect

Rust uses WebSockets for RCON. Ensure +rcon.web 1 is in your launch parameters.

const ws = new WebSocket('ws://IP:PORT/PASSWORD');

ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log(data.Message);
};

// Send command
ws.send(JSON.stringify({
  Identifier: 1, 
  Message: 'status',
  Name: 'WebRcon'
}));
