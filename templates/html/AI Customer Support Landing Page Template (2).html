Dúvidas? A gente responde.

Veja como o ForgeChat resolve os problemas que você enfrenta todo dia no atendimento.

É diferente de usar o ChatGPT direto?

Sim! O ChatGPT possui conhecimento geral e pode "alucinar" respostas. O ForgeChat cria um agente restrito apenas aos documentos e links que você fornece, garantindo respostas 100% alinhadas com sua empresa.

Preciso saber programar para configurar?

Zero código. A plataforma foi desenhada para qualquer pessoa usar. Basta arrastar seus PDFs ou colar a URL do seu site, e nós fazemos o resto. A integração com WhatsApp também é feita via QR Code.

A IA assume todo o meu WhatsApp?

Você tem controle total. Pode configurar para a IA responder apenas fora do horário comercial, ou habilitar o "handover" (quando a IA não souber responder, ela pausa e notifica um humano para assumir).

Posso usar o mesmo número de WhatsApp que já tenho?

Sim, suportamos tanto integrações oficiais (WhatsApp Cloud API) quanto via QR Code para números comuns (WhatsApp Web). Recomendamos a API oficial para alto volume.
