How to Play (Quick)

1) Host: Open Lobby, set name, Create Host. Open Connections, Create Invite. Send the Invite to friends. Paste their Answers and Apply.

2) Guest: Open Lobby, set name, Open Join Window. In Connections, paste the host Invite, Create Answer, send back to host.

3) Host presses Start Game. Turns rotate clockwise. Roll dice; buy if unowned; pay rent automatically. Chance/Chest, Taxes, Jail, Railroads, Utilities are implemented. No houses/hotels for speed.

Solo mode works offline. The host device is authoritative and syncs state to all clients.
