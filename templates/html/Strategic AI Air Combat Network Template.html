Algorithm Notes

DAA
Dijkstra

Computes the minimum cumulative edge weight path. Here it drives attack routing and dynamic escape rerouting when radar, weather, or blockages alter edge risk.

Time: O((V + E) log V) with a priority queue.

Prim

Builds a minimum spanning tree across friendly bases so command can maintain the lowest-cost logistics and communication network.

Time: O(E log V) with a heap.
