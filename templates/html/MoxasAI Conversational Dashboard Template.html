Flux & Intégrations

Prévoyez d’utiliser des clés factices puis remplacez-les dans Aura:

  • OPENAI_API_KEY="sk-openai-clé-factice"
  • ANTHROPIC_API_KEY="sk-anthropic-clé-factice"
  • STABILITY_API_KEY="sk-stability-clé-factice"
  • BING_API_KEY="sk-bing-clé-factice"

Recommandé: stockez ces clés côté serveur Aura (secrets) et proxiez les appels.

Étapes rapides

  1. 1. Créez les 5 collections avec les JSON ci-contre.
  2. 2. Ajoutez vos clés API dans la configuration Aura (secrets).
  3. 3. Paramétrez les règles d’accès: un utilisateur ne voit que ses données.
  4. 4. Branchez vos endpoints de paiement (Stripe) et webhooks.

Sécurité & Session

  • - Stockez les mots de passe sous forme de hash (SHA-256, idéalement bcrypt).
  • - Filtrez toutes les requêtes par userId côté serveur.
  • - Utilisez des tokens/HTTPOnly cookies si possible.
  • - Réinitialisez régulièrement les compteurs de quotas.

Paiements

Créez une session Checkout avec Stripe et mettez à jour l’utilisateur via webhook (checkout.session.completed ➜ isPremium=true, plan="premium").
