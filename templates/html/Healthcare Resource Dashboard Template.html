CareSync: Real-Time Resource Management

A production-grade, real-time web application designed to solve the critical problem of resource tracking across healthcare facilities. It provides live updates on bed availability, oxygen supplies, and critical care units using WebSockets, ensuring seamless coordination during emergencies.

Problem Statement

During mass casualties or pandemics, families and paramedics struggle to find available hospital beds or blood in real-time, leading to fatal delays.

The Solution

A centralized, real-time dashboard connecting all regional hospitals. It tracks inventory via WebSockets and predicts shortages using an AI-based triage algorithm.

System Architecture

Frontend (HTML, Tailwind, Vanilla JS)
REST APIs (JWT Auth)
WebSockets (Live Data)
Backend (Java Spring Boot)
PostgreSQL (Core Data)
AI Engine (Python/FastAPI)

Core Features

  • JWT Role-Based Authentication

    Secure login system differentiating between System Admins, Hospital Managers, and Public Users.

  • Real-Time WebSockets

    Instant updates to bed counts and critical resources without page refreshes.

  • AI Triage Recommendation (Bonus Feature)

    Integrates a lightweight prediction model to suggest resource allocation based on incoming patient severity.

hospitals id (UUID) manager_id -> users(id) Hospital profiles, locations, and contact info.
resources id (UUID) hospital_id -> hospitals(id) Tracks beds, ICU, ventilators, and oxygen levels.

REST API Endpoints

POST /api/v1/auth/login

Authenticates user and returns JWT token.

GET /api/v1/hospitals/{id}/resources

Fetches current resource counts. Requires Bearer Token.

PUT /api/v1/hospitals/{id}/resources

Updates bed counts and triggers WebSocket broadcast to all connected clients.

WS /ws/updates

WebSocket endpoint for real-time live dashboard tracking.

Spring Boot Backend Implementation

Below is the core logic demonstrating the WebSocket configuration and the REST controller for handling real-time resource updates.

WebSocketConfig.java 
package com.caresync.config;

import org.springframework.context.annotation.Configuration;
import org.springframework.messaging.simp.config.MessageBrokerRegistry;
import org.springframework.web.socket.config.annotation.*;

@Configuration
@EnableWebSocketMessageBroker
public class WebSocketConfig implements WebSocketMessageBrokerConfigurer {

    @Override
    public void configureMessageBroker(MessageBrokerRegistry config) {
        config.enableSimpleBroker("/topic");
        config.setApplicationDestinationPrefixes("/app");
    }

    @Override
    public void registerStompEndpoints(StompEndpointRegistry registry) {
        registry.addEndpoint("/ws/updates").setAllowedOrigins("*").withSockJS();
    }
}
ResourceController.java 
package com.caresync.controller;

import com.caresync.service.ResourceService;
import org.springframework.messaging.simp.SimpMessagingTemplate;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/v1/resources")
public class ResourceController {

    private final ResourceService resourceService;
    private final SimpMessagingTemplate messagingTemplate;

    public ResourceController(ResourceService rs, SimpMessagingTemplate mt) {
        this.resourceService = rs;
        this.messagingTemplate = mt;
    }

    @PutMapping("/{hospitalId}")
    public ResponseEntity<ResourceDto> updateResources(
            @PathVariable String hospitalId, 
            @RequestBody ResourceUpdateRequest request) {
        
        // Update DB
        ResourceDto updated = resourceService.updateResource(hospitalId, request);
        
        // Broadcast real-time update to all connected dashboard clients
        messagingTemplate.convertAndSend("/topic/live-resources", updated);
        
        return ResponseEntity.ok(updated);
    }
}

Deployment & Setup Guide

1. Database Setup

Ensure PostgreSQL is installed. Run the following to initialize:

CREATE DATABASE caresync_db;
CREATE USER care_admin WITH PASSWORD 'secure_pass';
GRANT ALL PRIVILEGES ON DATABASE caresync_db TO care_admin;

2. Backend Execution (Spring Boot)

Navigate to the backend directory and update `application.yml` with DB credentials. Then build and run:

./mvnw clean install
java -jar target/caresync-backend-1.0.jar

3. Cloud Deployment Strategy

  • Backend: Deploy the executable JAR on AWS EC2 or Render.com as a Web Service.
  • Database: Use AWS RDS (PostgreSQL) or Supabase for a managed database instance.
  • Frontend: Deploy the HTML/Tailwind/JS frontend files to Vercel or Netlify. Connect the base API URL to your deployed backend domain.
