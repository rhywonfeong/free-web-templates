Quick Accessibility Access

We are committed to providing excellent service to all customers, ensuring equal and convenient access to this website's information and services for everyone. If you encounter any access barriers, please contact us immediately.

Accessibility Statement

We are dedicated to ensuring that our digital presence is accessible to everyone, regardless of ability or technology used. We continuously improve the user experience for everyone and apply the relevant accessibility standards.

Standards & Guidelines

To ensure barrier-free web access, we benchmark our design and development against the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA .

These guidelines explain how to make web content more accessible for people with disabilities, and user-friendly for everyone. Conformance with these guidelines will help make the web more user friendly for all people.

Implementation Measures

Navigation Structure

Logical tab order and consistent navigation menus for seamless keyboard browsing.

Keyboard Access

Ensuring all interactive elements are fully operable via standard keyboard interfaces.

Semantic Markup

Proper heading hierarchy and HTML5 landmarks to support assistive technologies.

Visual Contrast

High contrast ratios between text and backgrounds to accommodate visual impairments.

ARIA Implementation

Use of WAI-ARIA roles to provide context for dynamic content and complex controls.

Responsive Design

Layouts that adapt to zoom levels up to 200% without loss of information or function.

Navigation Tips

For a better browsing experience, you can use the Tab key to navigate forward, Shift + Tab to navigate backward through interactive elements, and press Enter for assistance.
