Automatic daily backups with 30-day retention. Point-in-time recovery and disaster recovery plans.

Les 4 Phases Standard

PHASE 1: PLANNING

Définir scope, valider budget, organiser équipe.

PHASE 2: CONCEPT

Brainstorming, sketchs préliminaires, présentation concept.

PHASE 3: DESIGN

Plans détaillés (2D/3D), spécifications techniques, rendu photoréaliste.

PHASE 4: CONSTRUCTION

Supervision site, contrôle qualité, livraison.

Astuces & Meilleures Pratiques

Détaillez vos Devis

DON'T: "Architecture Services $50k"

DO: Séparez: Concept ($8k), Drawings ($4.5k), 3D ($6k)... Le client a plus confiance.

Toujours "Preview"

Générez et téléchargez le PDF pour vérifier la mise en page avant de cliquer sur "Send to Client".

Nommage Clair

Format recommandé :

Dates Réalistes

Ajoutez toujours une marge : +20% Planning, +15% Design, +25% Construction.

FAQ & Troubleshooting

Troubleshooting

Data Sync Issues

Force refresh (Ctrl+Shift+R). If persistent, clear Local Storage in DevTools.

Permission Denied

Check your role. Ask Admin to verify permissions or assign you to the project.

PDF Formatting

Avoid special characters in names. Re-generate PDF. Try a different browser.

File Uploads

Limit is 50MB. Compress files (zip) or split them if larger.

Common Questions

How do I create a proposal template?
Save any proposal as a draft with a generic name (e.g., "TEMPLATE - Villa"). Duplicate it when needed.
Can I edit a sent proposal?
No. For legal reasons, sent quotes are locked. Duplicate it to create V2.
How do I track budget?
Use the Financial Report in your project dashboard to see Budget vs Actual spend in real-time.

Glossaire

Proposal (Devis)
Formal document with services, pricing, and terms sent to a client.
Phase
Stage of a project (Planning, Concept, Design, Construction).
Go/No-Go
Approval criteria required to proceed to the next phase.
Deliverable
Tangible output of a phase (e.g., PDF Drawings, 3D Render).
RLS
Row-Level Security: System controlling data visibility per user.
Line Item
Specific service or product listed in a proposal.
