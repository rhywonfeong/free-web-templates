Frequently Asked Questions

How long does it take to set up?

You can be up and running in minutes. Simply clone the repository, install dependencies, and run the development server. Deployment is seamless with providers like Vercel.

Do you offer technical support?

Yes, all paid plans come with support. Starter plans have community access, while Pro and Team plans include priority email support from our engineering team.

Are there limits on customization?

None at all. Since you get full access to the source code, you can modify any part of the template, add new components, or integrate with any third-party API.

What integrations are supported?

Aplix is designed to be agnostic. It works beautifully with Supabase, Firebase, Stripe, LemonSqueezy, ConvertKit, and more.
