پرسش‌های متداول

آیا سروش قابلیت مدیریت ۱۰,۰۰۰ کاربر همزمان را دارد؟
بله، معماری میکروسرویس سروش به گونه‌ای طراحی شده که با استفاده از تکنولوژی‌های کانتینری (مانند Docker و Kubernetes) قابلیت مقیاس‌پذیری افقی (Horizontal Scaling) را برای تعداد کاربران بسیار بالا فراهم می‌کند.
فرایند آموزش تیم فنی ما چقدر طول می‌کشد؟
با توجه به محیط بصری و Low-Code، تیم‌های آشنا با مفاهیم پایه وب معمولاً طی ۲ هفته به تسلط کافی برای توسعه ماژول‌ها می‌رسند. دوره آموزشی جامع ۴۰ ساعته جزو خدمات استقرار است.
آیا امکان اتصال به سامانه‌های قدیمی (Legacy) وجود دارد؟
بله، سروش دارای ماژول Integration Bus قدرتمندی است که از طریق Web API، دسترسی مستقیم دیتابیس یا فایل، با سامانه‌های قدیمی ارتباط برقرار می‌کند.
