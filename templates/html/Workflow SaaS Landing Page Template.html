자주 묻는 질문

기존 데이터를 어떻게 이전하나요?

CSV, JSON 등 다양한 형식의 데이터를 간편하게 업로드할 수 있으며, API 연동을 통한 대규모 마이그레이션도 지원합니다.

정기 결제 해지는 언제든 가능한가요?

네, 계정 설정 페이지에서 언제든지 정기 결제를 해지하실 수 있으며 별도의 위약금은 발생하지 않습니다.

모바일 앱도 제공되나요?

현재 iOS와 Android를 위한 전용 앱이 제공되고 있으며, 웹 브라우저에서도 동일하게 모바일에 최적화된 경험을 제공합니다.
