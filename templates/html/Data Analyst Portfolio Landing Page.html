This starter mirrors your intended stack and IA. To turn this into a production app:

  1. Scaffold the app: 
    npx create-next-app@latest smit-portfolio --ts
cd smit-portfolio
npm i -E tailwindcss postcss autoprefixer lucide-react @tailwindcss/typography next-seo plausible-tracker
npx tailwindcss init -p
  2. Pages: create routes — /, /projects, /experience, /resume, /blog, /contact.
  3. Data: fetch pinned repos and recent commits from GitHub’s API using a token set in an env var: 
    # .env.local
GITHUB_TOKEN=ghp_xxx
    Map repo topics to badges, and fallback to the static seeds used here.
  4. Resume: serve /public/Full_time_Data.pdf and implement a print-friendly /resume route using print-only classes.
  5. Analytics: add the Plausible script in _document and configure your domain.
  6. SEO: add OpenGraph images, sitemap.xml, and robots.txt via next-sitemap. Include JSON‑LD for Person and Projects as shown.
  7. Deploy: push to a repo and deploy. Enable image optimization and caching headers.

Performance checklist: preconnect fonts, limit 3rd‑party scripts, avoid layout shifts, pre-size media, and lazy‑load below‑the‑fold content.
