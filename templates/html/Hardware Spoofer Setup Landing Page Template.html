03

Clean all disks except the USB

When you see the Windows Setup “Install now” screen, press SHIFT + F10 to open Command Prompt.

This is the screen you are looking for:

Once on this screen, hold SHIFT + F10 to bring up the Command Prompt.

Important: You must clean every disk except the USB. The clean command erases the selected disk, so do not select the USB.

First, run these two commands once. Click a command to copy it, paste it into Command Prompt, then press Enter.

Find the USB by its size.
Look at the Size column. The smallest disk is usually your USB. For example, if one disk is 32 GB and the others are 1 TB / 2 TB, the 32 GB disk is most likely the USB.
Skip only the USB. Every other disk must be cleaned AND converted to GPT.
For EACH disk except the USB:

Enter that disk number below, then run all 3 commands in order.

Finished that disk? Change the number above to the next non-USB disk and repeat all 3 commands again.
Example: Disk 0 → select disk 0 → clean → convert gpt, then Disk 1 → select disk 1 → clean → convert gpt.
Keep going until every disk except the USB is done.

Only after all non-USB disks are finished:

Close Command Prompt and continue to Step 04.
