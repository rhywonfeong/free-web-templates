Access Rights & Permissions

Manage role-based security policies across the Nexus platform.

Role Hierarchy

System Administrator

Full Access

Limit: 1-2 Users

Permissions: Full read, write, modify, and delete capabilities for all modules, including user management, configuration, and data exports.

Responsibility: Initial system setup, managing user roles, configuring workflows, and maintaining data integrity.

Reliability Engineer

Advanced / Power User

Permissions: Read/Write access to all asset data, maintenance history, and analytics tools. Ability to run RCA and RCM reports.

Responsibility: Analyzing equipment failures, creating FMEA/FMECA studies, and updating maintenance plans.

Restriction: May not have authority to change core system configuration or user access levels.

Maintenance Supervisor / Planner

Operational Access

Permissions: Read/Write access to work orders, scheduling, inventory, and resource management.

Responsibility: Planning preventive maintenance, assigning tasks to technicians, and ordering spare parts.

Restriction: Usually limited to data entry and planning, rather than system-wide analytical changes.

Technician / Maintenance Staff

Field Access

Permissions: Limited access, often read-only for asset history, but write access to update work orders, log hours, and close tickets.

Responsibility: Executing tasks and recording maintenance data.

Restriction: Cannot create new assets or modify preventive maintenance schedules.

Operator / Read-Only User

Observer Access

Permissions: Read-only access to specific dashboards or assets. Ability to submit failure reports or maintenance requests.

Responsibility: Reporting issues and monitoring the operational status of equipment.

External Vendor / Contractor

Scoped Access

Time-Based

Permissions: Extremely limited, temporary access restricted to specific assets or work orders they are contracted to repair.

Best Practice: Implement time-based access that automatically revokes access after a certain period.

Security Best Practices

Segregation of Duties

Prevent requesters from approving their own changes.

Use Scoped Roles

Define roles by function (e.g., "Pump Maintenance") over title.

Automate Provisioning

Auto-update/remove access to prevent "privilege creep".

Multi-Factor Authentication

Require MFA for all users, critical for admins.

Periodic review to ensure access aligns with duties.
