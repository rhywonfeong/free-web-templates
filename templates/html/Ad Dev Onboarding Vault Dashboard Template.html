R2 — Jonah Stack

ILL Seat Needed

GA4 GTM

Overview

Rent Manager CRM with Jonah website. Full GTM and GA4 implementation required. ILL seat needed for lead routing.

Website

Jonah

UTM Source

Sadie via Email

PMS

Rent Manager

UTM Format

?utm_source={assigned_by_sadie}&utm_medium=cpc&utm_campaign={campaign_name}

Setup Steps

1

Request ILL seat for Rent Manager

2

Get Jonah admin and GTM container access

3

Email Sadie for UTM source parameters

4

Deploy GTM container on Jonah site

5

Configure GA4 and ad pixels via GTM

6

Set up ILL lead routing to Rent Manager

7

Map Jonah form submissions to CRM

8

QA full funnel from click to CRM entry

Access Needed

Rent Manager ILL Seat
GA4 Editor Access
GTM Container Access
Jonah Admin Panel

Notes

Complex three-system setup. Recommend scheduling a kickoff call with all stakeholders before beginning implementation.
