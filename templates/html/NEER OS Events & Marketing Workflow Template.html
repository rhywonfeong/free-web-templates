Tier 1 – Ideal

Best-performing cycle

Events are locked 6–8 weeks in advance

Rooted Receives

  • Full event details
  • Partner information
  • Content and print requirements

Allows

Stronger narrative development

Better paid media learning

More considered creative and UGC planning

Example: By mid-February, April events are already locked.

Tier 2 – Healthy

Minimum recommended

Events are locked 4 weeks in advance

Still Allows

  • Proper campaign design
  • Clear approvals
  • Calm, predictable execution

This should be considered the baseline operating standard.

Tier 3 – Reactive

Exception only

Events locked inside 2–3 weeks

Consequences

Execution is possible, but:

  • Creative ambition is reduced
  • Media efficiency may suffer
  • Tighter trade-offs are required

This tier should be used only when unavoidable, not as the norm.
