How it works

Keep the same interface, but now powered with logic that validates n8n JSON, extracts nodes and connections, detects workflow order, and converts everything into a readable guide.

Add Workflow JSON

Upload a .json file or paste raw workflow content manually. The app accepts both input methods without changing the UI structure.

Parse & Validate

The app validates JSON, extracts nodes, connections, credentials, and workflow order, then handles empty or invalid workflows gracefully.

Generate Guide

Each node becomes a setup step with purpose and configuration instructions, then appears in a guide viewer with navigation and copy actions.
