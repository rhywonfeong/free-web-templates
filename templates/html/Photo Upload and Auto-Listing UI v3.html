How do I publish this on GoDaddy?
This page is static—no backend needed.
Linux Hosting (cPanel)
  1. Save this file as index.html on your computer.
  2. Go to GoDaddy → My Products → Web Hosting → Manage → cPanel Admin.
  3. Open File Manager → public_html (or your domain’s root folder).
  4. Upload index.html (and any assets you added).
  5. Visit your domain. If you see a cached page, hard‑refresh.
Managed WordPress
  1. Best: Add a subdomain (e.g., app.yourdomain.com) on Linux Hosting and upload index.html there.
  2. Or create a custom page template in your theme and paste this markup into the template file.
Website Builder
  1. Add a new page section → HTML embed.
  2. Paste the full markup and publish. Test on mobile and desktop.
Tip: Ensure SSL is on. In GoDaddy, enable HTTPS and redirect http → https for best results.
