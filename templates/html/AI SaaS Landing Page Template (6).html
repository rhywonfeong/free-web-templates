Вопросы и ответы

Как работает пробный период?

Вы получаете полный доступ ко всем функциям тарифа Pro на 3 дня. Карта не требуется. После окончания вы автоматически перейдете на бесплатный тариф.

Могу ли я использовать сгенерированный контент в коммерческих целях?

Да, все права на сгенерированный текст, код и изображения принадлежат вам. Вы можете использовать их в коммерческих проектах без ограничений.

Есть ли API для разработчиков?

Да, API доступно в тарифе "Бизнес". Мы предоставляем подробную документацию и SDK для Python и Node.js.
