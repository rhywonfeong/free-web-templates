Hover: лёгкий подъём, заливка, оранжевая линия.
ГД
Владелец системы и приоритетов.
  • Стратегия
  • Оргструктура
  • Финальные решения / эскалации
Граница: не управляет ежедневной работой цеха.
КД
Выручка и машина продаж.
  • Лид → ТЗ → КП → договор
  • Защита КП
  • Handover в ПМ
Граница: не рулит цехом и техархитектурой.
ТД
Архитектура и стандарты.
  • Техрешения
  • Допуск нестандартов
  • Обучение, сложные кейсы
Граница: не ведёт проект как ПМ.
ПМ
Сроки и коммуникация с клиентом.
  • План
  • CR (изменения)
  • Организация FAT/SAT, закрытие
Граница: не ставит задачи исполнителям в цех напрямую.
ОТС
Диспетчер цеха + качество.
  • Задачи в цех
  • Распределение нагрузки
  • Pre‑FAT, допуск к FAT/отгрузке
Граница: не дисциплина и не «порядок» — это ОПД.
ОПД
Порядок/дисциплина/5S + комплектность.
  • Порядок
  • Контроль исполнения
  • Комплектация на выезды/отгрузку
Граница: не принимает технические решения.

Единое правило передачи задач в цех

Чтобы сохранить прозрачные приоритеты, качество и предсказуемость — вход задач должен быть единым.

Большое правило
Любые задачи в цех — только через ОТС.
Запрещено
чтобы не ломать приоритеты и ответственность
  • Ставить задачи напрямую исполнителям
  • Менять приоритеты в обход ОТС
  • Выдёргивать людей из задач без согласования
Замещение
когда ОТС недоступен
Если ОТС отсутствует — функции входа задач выполняет ОПД.
Ограничение: без техрешений и без изменения ТЗ.
Поток (4 шага)
одинаково для проектов, сервисных задач и нестандартов
фиксируется статус
Шаг 01
Запрос/задача
ГД / КД / ТД / ПМ / Сервис
Шаг 02
ОТС принимает
и уточняет входные данные
Шаг 03
Распределяет
по исполнителям цеха
Шаг 04
Контроль + статус
прозрачно для офисных ролей
передача • приоритет • качество
Если кажется, что «быстрее напрямую» — это почти всегда дороже по потере фокуса и ломает приоритеты. Правило существует, чтобы скорость была системной, а не случайной.

RACI по ключевым процессам

Быстро свериться «кто делает», «кто отвечает» и «кого нужно согласовать/информировать».

Легенда RACI
R — делает
A — отвечает
C — согласует
I — информируется
Примечание: таблица — базовая. В отдельных проектах допускаются уточнения через ТД/ПМ, но принцип «вход в цех через ОТС» сохраняется.
