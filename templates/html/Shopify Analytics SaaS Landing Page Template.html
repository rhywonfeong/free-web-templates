Developer Friendly

Built for developers, loved by merchants.

Spark provides a robust API and fully customizable components. Whether you're using Liquid, Hydrogen, or a headless stack, integration is seamless.

  • Typescript support out of the box
  • Headless compatible (React, Vue, Svelte)
  • Zero-config CLI deployment
Read the API Reference
spark.config.ts 
import { Spark } from '@spark/sdk';

// Initialize the engine
const client = new Spark({
  apiKey: process.env.SPARK_KEY,
  shop: 'store.myshopify.com',
  features: {
    analytics: true,
    optimization: true
  }
});

// Track custom event
await client.track('purchase_complete', {
  value: 129.00,
  currency: 'USD'
});
