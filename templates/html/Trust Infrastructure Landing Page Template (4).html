Utility Layer

Digital Trust Stack Grader

A lightweight way to assess coverage across identity, verification, fraud, consent, governance, transparency, and recovery. The grader is designed as a practical entry point into the benchmark framework. Teams can quickly assess how complete their current trust stack is and use the output as a starting point for deeper evaluation.

/api/v1/grade-stack
$ curl -X POST https://api.trst.com/v1/grade-stack \
-d industry="fintech" \
-d risk_profile="high" \
-d active_modules="identity,kyb"
{
"assessment_id": "eval_9a8b7c6d",
"stack_profile": "fintech_onboarding",
"coverage_score": 42,
"categories_mapped": {
"identity": "strong",
"fraud_controls": "missing",
"consent": "weak"
},
"recommendation": "Review Fraud & Consent Frameworks"
}
