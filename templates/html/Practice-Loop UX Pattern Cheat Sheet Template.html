Core Patterns

Select to Simulate
Habit Formation

Micro-Commitment Laddering

Active Loop

Process Simulation

Start
5-min practice (Absurdly easy)
Build
Scale to 10m → 15m → 20m over 3 weeks
Track
Completion consistency, not duration

Signals to Track

  • Completion (Binary)
  • Hesitation time (Start delay)
  • Self-rated confidence (1-5)

If Struggling...

  • Reduce duration to 2 mins
  • Remove decision fatigue (pre-select task)
  • Switch to passive consumption mode

Architectural Ethics

This pattern prioritizes human dignity over metrics. We never optimize for addiction, only for sustainable, consensual behavior change. The user always retains the right to opt-out or reset without shame.
