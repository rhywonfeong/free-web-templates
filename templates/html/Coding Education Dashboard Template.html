# Problem: Two Sum
# Level: Beginner | Space: O(n) | Time: O(n)
def twoSum(nums: List[int], target: int) -> List[int]:
# Dictionary to store value and its index
num_map = {}

for i, num in enumerate(nums):
complement = target - num
if complement in num_map: # O(1) lookup time
return [num_map[complement], i]
num_map[num] = i

return [] # No solution found

1. Two Sum

Easy Hash Table Array

Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target.

You may assume that each input would have exactly one solution, and you may not use the same element twice.

Why Hash Tables?

The brute force approach requires nested loops O(n²). By utilizing a Hash Map, we trade space O(n) for time O(n). As we iterate, we store the number and its index. For each number, we instantly check if its complement (target - current) exists in our map.

Time Complexity O(n)
Space Complexity O(n)
