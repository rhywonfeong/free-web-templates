FAQ

Good to know.

What is a mechanical keyboard?

A mechanical keyboard uses individual switches beneath its keys. Different switch types can change how a keypress feels and sounds.

Which keyboard layout should I choose?

Choose 65% for a compact desk, 75% to keep a function row, tenkeyless for a familiar layout without a number pad, or full-size if you use the number pad often.

What is the difference between linear and tactile switches?

Linear switches move smoothly through a keypress. Tactile switches have a noticeable bump that provides physical feedback.

Can I choose my keycaps and switches?

Options vary by keyboard. Tell us which model and typing feel you prefer, and we’ll help you explore what’s available.
