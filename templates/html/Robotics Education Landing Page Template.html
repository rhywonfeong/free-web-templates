Structured Learning Paths

Curriculum designed to grow with the student, from block-based coding to advanced mechanical engineering.

Ages 6-9

Bot Builders

Introduction to logic and mechanics. Students build simple machines and use block-based coding to bring them to life.

  • Visual Block Coding
  • Simple Mechanics
  • Logic Fundamentals
Details
Ages 10-14

Code & Control

Transition to text-based coding (Python). Focus on sensors, loops, and autonomous robot navigation.

  • Python Basics
  • Sensor Integration
  • Problem Solving
Details
