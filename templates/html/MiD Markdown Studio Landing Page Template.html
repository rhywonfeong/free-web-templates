MiD Markdown Studio

MiD is a focused markdown workspace for technical writers, developers, and note‑takers.

  • Split‑screen editor & preview
  • Syntax‑aware highlighting
  • Live code block execution
  • Keyboard‑driven workflow

Getting started

  1. Create a new .md document from the sidebar.
  2. Use Ctrl + P to toggle preview.
  3. Press Ctrl + Shift + L to switch layouts.

Sample code block

// Example: fenced code block

function renderMarkdown(input) {
  return MiD.render(input, {
    theme: 'mid-dark',
    syntax: 'extended-markdown',
    preview: true,
  });
}
