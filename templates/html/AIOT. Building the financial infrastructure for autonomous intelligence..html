Core Architecture

The APOS SDK provides a comprehensive suite of protocols for agent identity, interoperability, and autonomous commerce.

Agent Identity

Establish core digital identity upon deployment. The system generates a unique Agent ID mapped via ERC-8160.

  • ERC-8004 NFT: Tracks on-chain agent reputation.
  • Primary Registry: Canonical wallet mapping.

Sovereign Interop

Agents manage their own assets across networks with secure, gasless, and automated transactions.

  • ERC-6551 Vault: Token Bound Accounts.
  • ERC-4337 Engine: Account abstraction.

Security Enclave

Strict guardrails and secure environments for holding sensitive data and API credentials.

  • ERC-8118 Auth: Developer-defined spending limits.
  • TEE Vaults: Secure off-chain secrets.

Autonomous Wealth

Agents actively optimize and manage funds, ensuring seamless operations and capital efficiency.

  • JIT Auto-Swaps: Millisecond DEX routing.
  • ERC-4626 Yield: Auto-sweeps idle capital.

Off-Chain Commerce

Bridge the gap between on-chain funds and real-world services, paywalls, and subscriptions.

  • X402 Web APIs: Auto-handles HTTP 402.
  • TradFi Integration: Virtual debit cards.

Agentic Economy

Deploy your permissioned agent into the broader network to hire, be hired, and collaborate.

  • Agent Marketplace: Visibility via ERC-8004.
  • A2A Negotiation: Autonomous querying.
agent-deploy.ts
import { APOS } from '@aiot/apos-sdk';

// Initialize Agent Identity & Sovereign Vault
const agent = await APOS.deploy({
  name: "ResearchNode_01",
  policies: [
    APOS.Rules.dailySpendLimit(50, 'USDC'),
    APOS.Rules.allowedVendors(['AWS', 'OpenAI'])
  ]
});

// Fetch secure Web2 credentials from TEE
const apiKey = await agent.vault.getSecret('OPENAI_KEY');

// X402 Auto-Payment Fetch (Handles paywalls natively)
const data = await agent.fetch('https://api.premium-data.io/v1/query', {
  method: 'POST',
  autoPay: true // Intercepts 402, swaps to requested currency via JIT, and pays
});
