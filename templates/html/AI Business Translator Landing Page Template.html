API для вашего бизнеса

Интегрируйте ShellTranslate в свою ERP, CRM или маркетплейс. Автоматический перевод переписки с поставщиками, карточек товаров и инвойсов.

POST /v1/translate/analyze 
{
  "text": "这个价格太贵了",
  "context": "negotiation",
  "target_tone": "polite"
}
// Response
{

  "subtext": {
     "intent": "resistance",
     "risk_level": "medium"
  }
}
