Can you explain how Promises work in JavaScript and provide a clean, modern example? I'm studying for an interview.
AI

A Promise in JavaScript represents the eventual completion (or failure) of an asynchronous operation. Think of it like a restaurant buzzer: you place an order, get a buzzer (the promise), and can continue talking while the food cooks. When it's ready, the buzzer alerts you (resolves).

A Promise is in one of three states:

  • Pending: Initial state, neither fulfilled nor rejected.
  • Fulfilled: Operation completed successfully.
  • Rejected: Operation failed.

Here is a modern example using async/await and the Fetch API, which is built on Promises:

javascript 
// Fetching user data asynchronously
async function getUserProfile(userId) {
  try {
    // await pauses execution until the Promise resolves
    const response = await fetch(\`https://api.example.com/users/\${userId}\`);
    
    if (!response.ok) {
      throw new Error('Network response was not ok');
    }
    
    const data = await response.json();
    console.log('Profile loaded:', data);
    return data;
    
  } catch (error) {
    // Catch handles any rejection in the chain
    console.error('Failed to fetch user:', error);
  }
}
