03 — Process

How a project runs

Four stages, each with a fixed scope and a written summary before the next begins.

01Discover

We walk the house, listen to how you use it, and set a realistic budget range.

02Design

Drawings, interior selections and permits, priced before anything is ordered.

03Build

One site manager, one crew, and a written update at the end of every week.

04Reveal

Deficiency walkthrough, care guide, and a two-year workmanship warranty.
