MCP é uma forma de conectar o agente do Antigravity a ferramentas externas. Sem MCP, ele só enxerga o que tá no seu editor.

Com MCP, ele enxerga a documentação atualizada, os componentes reais, os dados do banco e os resultados dos testes. Ele para de adivinhar e começa a trabalhar com informação real.
