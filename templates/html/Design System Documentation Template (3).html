System Identity

Primers is an enterprise-grade design system built for scalability and consistency. It serves as the single source of truth for product teams, bridging the gap between design and engineering with a shared language of tokens and components.

Efficient

Built for speed without compromising quality. Components are optimized for performance and accessibility out of the box.

Modular

Atomic design principles allow for infinite composability. Build complex interfaces from simple, robust primitives.

Inclusive

Accessibility is not an afterthought. WCAG 2.1 AA compliance is baked into every component interaction and state.

Design Tokens

Semantic tokens that store visual design attributes. These are the atoms of the Primers system, ensuring consistency across platforms.

tokens/global.json 
{
  "color": {
    "primary": {
      "base": "#18181b",
      "hover": "#27272a"
    },
    "surface": {
      "default": "#ffffff",
      "subtle": "#fafafa"
    }
  },
  "spacing": {
    "xs": "0.25rem", // 4px
    "sm": "0.5rem",  // 8px
    "md": "1rem",    // 16px
    "lg": "1.5rem"   // 24px
  }
}
