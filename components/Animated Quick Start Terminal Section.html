Quick Start

Deploy in four commands

From zero to a live AI endpoint in under five minutes. Just install, authenticate, deploy, and go.

nova-cli — quick-start
1 # Install the Nova CLI
2 $ npm install -g @nova/cli
3 + @nova/cli@3.2.1 installed
4
5 # Authenticate with your API key
6 $ nova auth login --key sk_live_your_api_key
7 Authenticated as team@company.com
8
9 # Deploy a model to production
10 $ nova deploy --model llama-3-70b --region us-east-1
11 Provisioning GPU cluster... done
12 Model deployed at https://api.nova.ai/v1/llama-3-70b
13
14 # Test your endpoint
15 $ nova test --prompt "Hello, Nova!"
16 Response (42ms): "Hello! I'm ready to assist..."
